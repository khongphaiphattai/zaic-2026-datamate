2.-Tính năng mới: Test Solution (Kiểm tra Docker Image):
Hệ thống đã chính thức mở tính năng Test Solution trong mục “Portal” trên website chính thức của cuộc thi Zalo AI Challenge 2026. Tính năng này hỗ trợ các đội chạy thử Docker image để phát hiện lỗi sớm (như thiếu thư viện, sai định dạng đầu ra/output, v.v.).
Cách sử dụng:
Truy cập mục “Portal” trên https://challenge.zalo.ai/ => Chọn đề bài tham gia => Mở tab “Test Solution”.
Nhập Google URL và mã Checksum MD5 của Docker image Nhấn Submit Test.
Khi hệ thống hoàn tất, nếu kết quả lỗi, các đội có thể chọn View full log để xem chi tiết log xử lý. Trong trường hợp kết quả đã nộp thành công, hệ thống sẽ không hiển thị chi tiết log.
Lưu ý quan trọng:
Kết quả từ Test Solution chỉ mang tính chất kiểm tra thử, không tính vào số lượt nộp bài chính thức và không dùng để đánh giá kết quả thi.
Tính năng sẽ đóng vào lúc 23:59 (GMT+7) ngày 15/11/2026.

Lượt chạy thử: Tối đa 01 bài/ngày cho mỗi Đội thi hoặc Thí sinh cá nhân.

2. [IMPORTANT] New Feature: Test Solution (Docker Image Verification):
The Test Solution feature is now officially available on the portal. This feature allows teams to test-run their Docker images to detect errors early (such as missing libraries, invalid output formats, etc.).
How to use:
Access the "Portal" at  https://challenge.zalo.ai/  =>  Select your track => Open the "Test Solution" tab.
Enter the Google URL and MD5 Checksum of your Docker image Click Submit Test.
Once the system has finished processing, if the result shows an error, the Team may select “View full log” to view the detailed processing log. If the submission is successful, the system will not display the detailed log.
Important Notes:
Results from the Test Solution feature are strictly for trial testing, will not count towards official submission limits, and will not be used for evaluation.
This feature will close at 23:59 (GMT+7) on November 15, 2026.
Usage Limits:
Test Runs: Maximum of 01 submission per day per Team or Individual Participant.
Retries: Up to 05 retry attempts are allowed in case of technical issues related to the link, checksum verification, or file downloading process.
